# robot_ws

ROS 2 workspace for simulating and building an outdoor mobile robot (campus UGV), packaged in Docker so it runs the same on any machine.

## Stack

| Component | Version |
|---|---|
| OS (container) | Ubuntu 24.04 |
| ROS 2 | Jazzy |
| Simulator | Gazebo Harmonic |
| Navigation | Nav2 + robot_localization |
| Host | WSL2 (Windows) or native Ubuntu |

## Repo layout

```
robot_ws/
├── src/              # ROS 2 packages (mounted into the container)
├── docker/
│   └── Dockerfile    # image recipe
├── .devcontainer/    # optional VS Code dev container config
├── compose.yaml      # run settings: GUI, networking, devices
├── CLAUDE.md         # instructions for Claude
└── README.md
```

`build/`, `install/`, and `log/` are generated by colcon and are git-ignored.

## First-time setup on a new machine

### 1. Install Docker

**WSL2 / Ubuntu:**
```bash
sudo apt install docker.io docker-compose-v2 docker-buildx
sudo usermod -aG docker $USER
sudo systemctl enable --now docker
```
Then restart the shell (on WSL: `wsl --shutdown` in PowerShell, reopen WSL).

If `systemctl` fails on WSL, add this to `/etc/wsl.conf` and restart WSL:
```ini
[boot]
systemd=true
```

Check: `docker run hello-world`

### 2. Clone and build

```bash
git clone https://github.com/<you>/robot_ws.git
cd robot_ws
docker compose build
```

### 3. Open a shell in the container

```bash
docker compose run --rm ros
```

### 4. Build the workspace (inside the container)

```bash
colcon build --symlink-install
source install/setup.bash
```

## Native Ubuntu (not WSL)

In `compose.yaml`:
- Remove the `/mnt/wslg` volume and the `WAYLAND_DISPLAY`, `XDG_RUNTIME_DIR`, `PULSE_SERVER` lines
- Run `xhost +local:docker` on the host before starting the container

## Optional: GPU and USB

In `compose.yaml`, uncomment:
- **GPU (WSL):** the `LD_LIBRARY_PATH` env, `/usr/lib/wsl` volume, and `/dev/dxg` device
- **ESP32 serial:** the `/dev/ttyUSB0` device (on WSL, attach it first with [usbipd-win](https://learn.microsoft.com/en-us/windows/wsl/connect-usb))

## Troubleshooting

| Error | Fix |
|---|---|
| `permission denied ... docker.sock` | Not in `docker` group yet — `sudo usermod -aG docker $USER`, then restart WSL |
| `could not connect to display` | `echo $DISPLAY` on host should print `:0`; if empty, restart WSL |
| `COPY failed: src not found` | Build from repo root, not from `docker/` |
| Gazebo slow / black screen | Enable the GPU lines in `compose.yaml` |
